# 项目二：改进 FilmDB 数据库与课程材料

## 引言

课程中提供的数据库示例 `filmdb.sql` 是一份非常有价值的资源。  
然而，其中的内容需要更新，以纳入最近上映的电影。  
本项目的目标是通过加入新上映的电影来刷新数据库，并改进相关课程材料。

## 任务

### 1. 数据库改进

- 找出当前数据库中尚未包含的近期电影列表。
- 设计并执行将这些新电影数据加入数据库的策略，同时确保数据的一致性与完整性。
- 说明获取电影数据所使用的方法，以及进行数据校验的具体步骤。
- 确保更新后的数据库仍然保持所有必要的关联关系和约束。
- **[new]** 确保更新后的 `filmdb.sql` 能同时被 PostgreSQL 和 openGauss 支持。  
  若无法同时兼容，请分别为 PostgreSQL 和 openGauss 提供两份不同的 SQL 文件。

### 2. 课件讲义审查

- 审查全部课件与讲义内容，找出过时内容、错误或需要改进的部分。
- 提出具体的更新建议，包括更正信息、补充说明或改进后的示例。
- **[new]** 增加与 openGauss 相关的示例和内容，因为当前版本尚未包含 openGauss。

### 3. 课程内容建议

- 提出可加入到本课程中的新主题或新模块。
- 说明这些主题的相关性，并解释它们如何契合当前数据库管理或相关领域的发展趋势。
- 对每个建议加入的主题，给出简要内容纲要，包括关键概念、学习目标以及可能的实践练习。

## 报告要求

本项目为个人项目，每位同学必须单独提交一份报告及相关支持文件。  
报告应包含以下部分：

1. **数据库更新过程**
   - 详细说明用于识别并加入新电影数据的方法。
   - 解释在更新过程中如何保持数据的一致性与完整性。

2. **课件讲义评估**
   - 列出需要更新的具体课件或讲义内容，并附上相应的修改或改进建议。

3. **课程提升建议**
   - 列出建议新增的课程主题，并附上相应的理由及详细的内容大纲。

## 提交规则

- 项目截止时间为 **12 月 14 日 23:59**，逾期提交将获得 0 分。
- 报告须以 PDF 文件形式提交（文件名为 `report.pdf`），并附上所有相关支持文档。  
  **不要** 将所有文件压缩成一个压缩包提交。
- 你可以使用 AI 工具（如 DeepSeek、ChatGPT）来帮助理解概念或配置软件，但需注意：
  - 不要使用 AI 生成质量低劣或无关的文本。
  - 确保所有内容对读者来说都是有意义的、简洁的且有价值的。
- 报告应结构清晰、条理分明，并能有效突出本项目的关键内容。
